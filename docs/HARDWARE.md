# 黄山派选型复评

日期：2026-09-22。用户已选择退 Nano、改用立创黄山派作为唯一原型主板，接受仍需补齐 PPG、电池、电机和佩戴固定结构；随后明确确认 Nano 退货完成、黄山派已下单。成交价、订单附件、到货和实物版本尚未核实。代理没有操作订单、采购、联系卖家或刷写设备。

## 决定与边界

主线从 Nano R16N16 改为立创黄山派 SF32LB52-ULP，SDK 板名 `sf32lb52-lchspi-ulp`。保留 SDK v2.5.1 提交 `421126d9f476ed8e2a6f0b0ca28a9f241c182e65` 和 `sdk.lock.json` 的两个子模块版本，仅切换板型。现有 Nano 产物是历史编译证据，不能烧录到黄山派。

预算仍为 500 元；起点仍为 2026-09-21，三个月目标日期 2026-12-21，连续试戴一周。首版功能、Gadgetbridge 8h 实验上限和七天续航路线判断不变；不因为新增板载地磁、环境光、音频而扩展首版。

## 为什么改变排序

旧采购核验将黄山派列为条件候选，主要缺口是可核验供货与完整报价，并非技术否决。当时检索集中在思澈淘宝店，遗漏了立创商城销售渠道；也没有充分计入 Nano 后续外接传感器、电池电源和振动驱动的成本与工时。此次复评找到立创官方文档指向的商品，原来的供货缺口已获得页面证据。

| 项目 | Nano R16N16 | 黄山派 |
|---|---|---|
| 芯片 | SF32LB52JUD6 | SF32LB525UC6，同系列但非相同料号 |
| 内存 | 16MB PSRAM + 16MB NOR | 8MB PSRAM + 16MB NOR |
| 板屏价格 | 2026-09-21 页面 109.51 元 | 2026-09-22 页面 133 元，运费/结算另计 |
| IMU | 需外接 | 板载 LSM6DS3TR-C；另有 MMC5603NJ、LTR-303ALS-01 |
| 电池电源 | 需补齐 | 板载充电、电源控制和电池接口，电池另选 |
| 振动 | 需电机与驱动 | 已有驱动和焊盘，电机另选 |
| PPG | 需外接 | 官方清单未列，仍需外接 |
| 功耗测量 | 需核对隔离/接入路径 | VBAT、VSYS、VCC_3V3 跳线提供串表路径 |
| 软件入口 | 已有本项目历史三目标构建 | 固定 SDK 明确列入 watch、gui_pm 和 sensor 示例支持范围 |

这次选择重视外围集成与可测量性。尚无证据表明首版必须用 16MB PSRAM；也没有实测证明黄山派 8MB 满足最终资源峰值。内存和整机功耗均保留为验收项。

## 源码核验及剩余风险

- `example/rt_device/sensor/README.md:6` 明确支持黄山派；`:43` 指定 PA39/40，示例用 I2C3。`src/main.c:26` 初始化 LTR303、MMC56X3 和 LSM6DSL 路径，`:33` 未使用中断，`:74` 设置较高 ODR，`:116` 每 100ms 轮询。不能把它直接视为低功耗采样实现；LSM6DS3TR-C 实物 ID/驱动兼容、FIFO、中断与退出仍要验收。
- 官方扩展口有传感器 I2C 和可复用 GPIO，为外接 PPG 提供路径；但尚未形成具体模块的接线图、电压/上拉/地址/中断分配和贴肤结构，不因存在接口就认定完成接入。
- `sf32lb52-lchspi-ulp_base/bsp_lcd_tp.c:24` 的关屏函数还会操作 3.3V、音频及充电 I2C 引脚；`:55` 的开屏会开启音频 PA。`bsp_power.c:36` 的深睡恢复会开启传感器电源并访问充电器。屏幕、充电和传感器共享电源行为须在联合实验中检查，不把黑屏等同于整板最低电流。
- `customer/peripherals/charger/aw32001/aw32001.c:403` 初始化请求 4215mV。电池必须核对允许充电电压/电流、保护及极性；文档中的最大 4.5V、默认约 450mA 和推荐容量不是任意电芯可直接接入的保证。先沿用 USB 调试顺序。
- 源码和公开示例不证明本项目黄山派运行成功。当前编译结果单独记录在 [构建说明](BUILD.md)，全部硬件验收见 [到货清单](ACCEPTANCE.md)。
