# 电池主页面

本轮授权见[共识](BASELINE.md#battery-page-20261018)，活动状态和唯一下一步只见[STATUS](STATUS.md#current)。参考用户图2／3的层级：返回／时间、大号电量、充电状态与辅助信息；当前只实现电池主页面，长续航模式、续航优化及可用天数另轮。

## 所有权与数据

- `ui/xml/screens/screen_battery.xml`持有390×450黑底布局，80px数字、状态／原因、电压卡片及估算说明；经官方Pro GUI导出。新`battery_80`来自既有Sans TTF的数字／百分号／波浪号／未知标记子集，不改中文源字库。
- 沿用`WRISTFLOW_SURFACE_SYSTEM`及battery稳定ID，设置、应用列表和电量卡片进入同一页面，登记能力由占位改为READY；返回、KEY1、离栈回收和息屏规则由原shell／apps持有。
- `apps::render_power()`只绑定已有快照，不读取硬件或计算电量；有效百分比复用共同formatter，未知显示`--%`，有效节点电压独立显示。USB有效／无效／未知仅表达PG观测，不断言电缆或电池在位。
- 状态／原因复用已有charger显示映射；ACTIVE／FULL青绿、FAULT红色，其余灰色，图标不创建动画。时间未校准为`--:--`。估算注明“电压估算，仅供参考”；UI Demo既有固定快照显示`53%`，来源注明“演示数据”，不接入估算服务。
- 不修改[电压估算算法](BATTERY-ESTIMATE.md)、充电控制参数、插接覆盖层、采样／PM、持久化、协议或SDK锁。没有新按钮、后台任务、timer或设备命令。

## 验证边界

2026-10-18软件闭环基于`46a2c23`及本变更，精简证据见[电池页验证](evidence/2026-10-18/battery-page.json)。本地长日志和截图保存在D盘隔离工作树的忽略目录`artifacts/battery-page*`及`artifacts/host/renders/`，不是仓库内可下载附件。

- **源码与真实渲染**：官方Pro2.0.1／预览LVGL9.4.0完成GUI导出、字体编译及100%预览；固件LVGL同为9.4.0。信息卡文字偏暗已在XML显式设置前景色后重新导出。真实LVGL七态快照检查电压独立有效、USB三态、充电／FULL／FAULT、估算`~59%`／`~100%`，无明显缺字、重叠或越界；具名字形和`~100%`尺寸断言通过。设置、卡片及列表入口、刷新、返回和离栈回收由相关主机用例覆盖。独立只读审查未发现阻断；Demo固定快照来源已核对，不把假设注入估算的组合当成实际路径。
- **主机测试**：Debug完整CTest45/45（21.55秒）、Release相关7/7（3.45秒）。首轮Product UI旧断言仍把battery判为PLACEHOLDER而失败，改为READY后单项、完整及Release均通过。未改变电量算法或充电控制。
- **固件编译**：既有隔离包装器调用当前`Build.ps1 -Example product/ui_demo -Jobs 6`及官方SCons，均退出0。Product `20261018-142914-525`／BIN`7b4c5768…`，UI Demo `20261018-143009-422`／BIN`f85674e0…`；419／383源码与29／22产物重哈希一致，新增页面／字体在实际编译清单和map中。SDK及子模块锁定且干净。新数字字体C文件134,474B，链接位图19,639B；Product BIN较上一版增加21,968B。
- **硬件未验**：没有UART、复位、烧录或测量；设备最后估算版`fc4d6703…`的结果不作为新布局验收。后续只对精确候选另轮核对供电、下载及入口／返回／刷新／睡醒显示，不因此声称SOC校准、物理终止、电流或续航通过。
