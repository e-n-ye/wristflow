# 硬件操作清单与验收

<a id="battery-motor-preparation"></a>
## 2026-10-14 电池与电机接入准备

用户已明确把正式功耗测量延期，当前优先电池／电机。本节覆盖下方 USB 粗测方案中“先做测流转接／基线，电池与电机后接”的顺序；下方保留方法和旧条件，不自动执行。活动项与唯一下一步仍见 [STATUS](STATUS.md#current)。本轮调整说明与契约，没有修改固件或操作设备。

| 当前接入对象 | 软件与资料准备 | 代焊／现场动作 | 最小通过条件 |
|---|---|---|---|
| 电机（可在现有 USB 下独立完成） | 核对同版 VIB 输出、驱动器件／供电及电机负载；准备默认关闭、有时限的启停控制，正常结束／取消／错误退出均关断；先不接整套提醒策略 | 全断电核对 VIB 正负，电机两线焊到已确认的输出焊盘、绝缘并固定外壳和线束；通电后先执行有时限的短脉冲 | 能启动、按时停止，结束后输出确实关闭，无异常发热或主板复位；记录试验固件、供电、脉冲时长及现象。驱动余量不足或规格不明先核验，不靠堵转试极限 |
| 电池 | 优先解决 H2 所列启动／唤醒／复位下的充电电压、电流和使能顺序，核对实际电芯限制；保持 SDK 锁，不只在应用末尾补一条设置 | GH 尾线与成品电池已有引出线接合；一次仅处理一极并立即绝缘，测最终插头极性／开路电压；允许独立供电后拔 USB 试运行，充电在配置和台架核验后单独验证 | 电池独立启动／显示／BLE／息屏恢复正常；充电另有电池端电压、电流、温度和终止证据，不能只看图标 |

电池线束可与电机准备并行，通电每次只新增一种负载。电机不再等待整机低功耗基线；电池也不等待正式功耗测量，但不能跳过它自身的充电限制／极性核验。当前旧固件的 4215mV 请求与先启充路径尚未处理，不能直接把 4.2V 电芯插上边调边试。只有 USB 断开且不存在其他充电来源的独立放电，与 USB 插入充电是不同测试，不要求拿充电曲线代替独立供电结果。

这一阶段仍要借普通万用表做极性、电压与必要的电气检查，充电／负载验证按所需仪器准备；这不等于恢复微安级待机、动态积分或续航测量。MAX30102 的黄山派飞线继续暂缓，辅助板候选保持，测流转接件现在无需制作。

<a id="first-power-session"></a>
## 2026-10-14 首轮 USB 功耗现场操作单（前序方案，已延期）

这是此前给用户、代焊者和仪表出借者准备的万用表粗测方案，**用户已选择延期，以下“这次／首轮／先不接电机”等表述仅属当时条件**。它没有执行，也不是已具备的专业低功耗测量系统；不能把它作为当前电池／电机接入的前置。系统说明见 [当前系统与低功耗说明](PM-EVENT-WAKE.md#current-power-system)，活动项只在 [STATUS](STATUS.md#current)。

### 1. 出发前带什么，先告诉帮忙的人什么

带黄山派和屏幕、原 USB 线、手机、三个原跳线帽、1.27mm 双排排母、红黑线、热缩管／PI 胶带。电池和 GH 尾线可一起带去核极性，但分别绝缘、不插板。拍下原三对跳帽、FPC 和 BAT 插座方向；保留最近烧录记录（最近已知 `0ddcd89`），若之后刷过其他版本先记清。不用为了测流先升级固件。

可以直接给代焊者看这段：

> 先不焊电机和心率模块，不给电池充电。请确认我这块板的 CN3 编号，做一个 1.27mm 母座到可夹持端子的可拆测流转接。正常要保持 5–6、7–8、11–12 三对桥接；测 VSYS 时只断 7–8，7 是设计中的源侧、8 是负载侧。两个测流端标“7／源”“8／负载”，平常用可拆短接塞连通，串表时移除短接塞。不要直接把大表笔顶在细针上。最后请断电核导通和绝缘，再借合适万用表串测。

这里的“转接件”是拟制作的小线束／小板：匹配 CN3 的 1.27mm 母座 → 两根独立导线 → 方便固定表线的端子，中间保留可拆短接。用户已有排母只是其中一部分，并没有确认存在专用成品转接板。它仅解决接触和间距，不提供电流记录、量程切换或峰值捕获；当前无需制作。

借表时需要的不是某个品牌，而是：可测 DC 电压、有可用保险保护的 DC 电流档，能承受启动／唤醒电流；确认该档精度、分辨率、负担电压及允许连续测量时长。**尚不知道型号，不能现在指定插哪个 mA／A 孔或直接用 µA 档。** 优先再借一只电压表，以便串流时看负载电压和表的压降。只有一只合适表也可做初测，压降列必须注明未同时测得；高档读不出小电流就写“低于该档分辨率”，不要写 0mA。

### 2. 先确认这三个跳线分别测什么

以下是 [官方 V1.2 设计包](https://downloads.sifli.com/hardware/files/documentation/ProPrj_%E7%AB%8B%E5%88%9B%C2%B7%E9%BB%84%E5%B1%B1%E6%B4%BESF32LB52%E5%BC%80%E5%8F%91%E6%9D%BFV1.2%28202504250924%29.epro) 的编号，**不是照片上的左／右方向**。实物版本和 pin1 必须由代焊者按丝印、定位标记及电路对应确认，拍一张标号照片后再拔帽；无法对应就停在无源准备。

| CN3 针号 | 设计网络 | 这次处理 |
|---|---|---|
| 5—6 | VBAT_S—VBAT | 保持短接；没有电池时不靠这对测 USB 系统耗电 |
| **7—8** | **VSYS_S—VSYS** | **首轮测量对象：7 为源侧，8 为下游负载侧** |
| 11—12 | VCC_3V3_S—VCC_3V3 | 保持短接；以后定位 3.3V 支路再单独测 |
| 3／4／9／10 | GND | 电压测量可选已确认的其中一个地；不是本次电流表黑笔接点 |
| 1／2 | USB_VBUS_5V | 本轮不接外部电源、不与其他针短接 |

三组都只是串接测量入口，本身不输出功耗数字。按设计网络补充各自能回答的问题：

| 测量路径 | 电流读数的含义 | 不能据此判断 |
|---|---|---|
| 5—6 | 电池与充电器／系统之间的净电流；仅电池供电时主要看放电，USB 同接时可能充电也可能放电，需记方向 | USB 系统总耗电；没有电池时不提供正常电池续航证据。电池侧 D18 漏电不经过此测点 |
| 7—8 | VSYS 下游各支路的合计输入电流，包括相关主控、显示和外围供电 | 充电器全部输入损耗、独立 USB 转串口耗电或所有电池端损耗 |
| 11—12 | 名为 VCC_3V3 的特定支路，设计中包含卡座、屏幕接口一路供电和相关上拉 | 全部 3.3V 器件、完整屏幕电流或电机电流；屏幕另有 VSYS_1 供电，电机用模组 VDD33_VOUT 支路 |

核验来源为下述官方包的同一 PCB：CN1 电池正端→VBAT_S→CN3-5/6→U3 BAT，见 `:4060,4319,4318,5178`；U4 输入 VSYS_1、输出 VCC_3V3_S 及 CN3-11/12，见 `:4140,4142,4313,4312`；卡座／屏幕接口支路见 `:4280,4088`。这些是设计证据，实物仍需对应。功率还需要同一边界的电压，能量需要随时间积分，不能把三轨电流相加当总功耗。

设计包 `PCB/e4947da8b8a84953a988023242fbea49.epcb:4316–4317` 给出 CN3 8=VSYS、7=VSYS_S；`:5173,5175` 给出 U3 输入 VBUS_5V、SYS 输出 VSYS_S。`SHEET/bfbe9dd79a064614aebc68082ceec943/14.esch:708` 明确 7–8 可断开 VSYS 下游。CH340 由另一路 VBUS_5V→CH_3V3 供电（同 PCB `:4471–4474,4151,4154`）。本轮主代理对这些关键网络做了内存读取抽查。

所以本次表头应写 **“USB 供电下、CN3 7–8 的 VSYS 下游电流”**。它覆盖相关主控、显示及下游供电支路，不能包含所有 USB 上游损耗／转串口自耗，更不能叫电池整机电流。三条轨有上下游关系，不能简单相加。板上 UART 等信号也可能造成旁路供电；未核实前保留测量边界，打开跳线后负载侧不为零不能自行认定编号反了。

### 3. 先焊什么，怎么做

1. **全部断电**：拔 USB、其他电源／调试线，电池保持分离。原板先不动焊点。确认残余电压消退后才用通断档。
2. **先做无源测流转接线**：按现场空间选择能单独接 7–8 的匹配母座；若整条排母会覆盖原跳帽，就在转接件上明确补通 5–6、11–12，并为 7–8 做可拆短接。其余脚留空、绝缘。不把 1.27mm 母座当成 2.54mm 杜邦口，不强插。
3. **由代焊者焊母座／端子侧**：导线尽量短、方便夹持，先套热缩管，剥线约 2–3mm，线端和焊尾分别少量预上锡，再加热接合；冷却后检查焊锡润湿、无散丝／锡桥，轻拉确认牢固。温度按焊锡和端子选择，不长时间烫塑料。每根焊尾单独绝缘并做应力固定；外露测点只留在端子处。不用在主板细排针上直接堆锡飞线。
4. **转接件离板测通断**：标记端逐根只通到指定针；拔掉短接塞时两个测流端不通，插回时相通；非目标针之间无意外短路。若使用全排母，特别检查 5–6、11–12 已桥接、7–8 可独立开断。照片记录正反面与插合方向。
5. **装板后再次断电复核**：确认针号无错位、没有整体反插、其他两对供电没有丢失。必要时由代焊者对照同版设计在可接近测试点核对网络；不要让新手直接用粗表笔探充电 IC 细引脚。正常短接状态先做一次 USB 启动／显示／KEY1 检查，再断电。

**电池线可作为顺便准备项，首轮测流不依赖它。** 只有 GH 插合／线序已确认才处理：先用电压档辨认电芯两线正负，把未处理的一极单独包好；先套热缩管，仅连接已有引出线与 GH 尾线的一极，接好并绝缘后才处理另一极，禁止同时剪两根线，不直接焊电芯或极耳。最终从插头插合面测电压与极性、标锁扣方向，放回独立绝缘袋，**不插 BAT**。当前 SDK 请求 4215mV 且充电控制顺序未闭环，而电芯标签是 4.2V；后续按 H2 修复和台架核验，不能拿真实电池直接试充。

**这次先不焊电机到 VIB。** 先拿到无电机基线；后续在核对驱动／额定电流后，断电将两线接 VIB 正负焊盘、绝缘固定，配合能启停的短脉冲测试固件单独测增量。现有 Product 没有已接入的电机提醒服务，焊好不会自动振动。MAX 的七针排针可在选定 H7/F411 和安装方向后再焊；模块电压、电平和具体板针脚未知时不预填接线图。SPK 是喇叭口，不用于这次接入。

### 4. 先测电压，再断电改为串电流

先选定唯一 USB 电源和线，移除外加串口、调试器及其他外供线；电池不接。首轮一直使用同一个 USB 来源。不要在一组数据中途换电脑口、充电头或长线。

**电压接法（跳线正常短接时）**：黑笔 COM，红笔 VΩ，选择覆盖该电源的 DC 电压档。用固定端子／合适细夹将黑笔接已确认 GND，红笔接 VSYS 测试端；通电分别记录亮屏与自然息屏的电压。也可测 7、8 对地，正常短接时两者应接近。单表这时只测电压；抄完关电，不在带电时换孔。电池开路电压若顺便测，单独记在电池准备表里，不能混进 VSYS 电压。

**电流接法**：

```text
唯一 USB 电源 → 板上电源路径 → CN3-7（VSYS_S）
                                │
                           红笔：电流插孔
                              [万用表 DC A]
                           黑笔：COM
                                │
                          CN3-8（VSYS）→ 下游负载 → 板上 GND

7—8 原跳帽／转接短接塞：移除；5—6、11—12：保持桥接。
```

按以下动作顺序操作，**电流表 COM 在本次接 8 脚，不接地**：

1. 拔 USB，取下 7–8 的短接塞／原帽；检查没有第二条导线暗中把这两个端子短接。
2. 按借到的仪表说明选择能承受启动和唤醒峰值的档位／插孔，从较高合适量程开始；记录型号、插孔、量程、分辨率及允许时长。仪表没有合适保护或量程就不串入。
3. 红笔电流输入固定接 7／源，黑笔 COM 固定接 8／负载；端子分开绝缘，不能手持两根粗笔尖抵住 CN3。
4. 检查之后接 USB，观察正常启动、有无过载指示、反复重启或熄屏后无法唤醒。发生异常立即拔 USB，恢复短接排查；不能把受仪表压降影响的异常当成固件功耗。
5. 若量程太粗，**断电后**再按说明换档／插孔；较小档也必须承受下一次启动／按键／通知峰值。不能因为当前息屏电流小就直接换 µA 档。没有合适档位时保留粗测结果。
6. 有第二只表时，电压档测 8 对 GND 得负载电压，再测 7 对 8 得整段测流路径压降（含导线与接点）；记录亮屏／息屏各自结果。只有一只表不能同时测这些量：前面的正常跳线电压只是对照，串流时压降写“未测”，不把不同时间读数当同时测量。

电流档绝不跨接 USB 正负、电池正负或 VSYS 对 GND。若以后使用示波器，普通接地探头不能把地夹夹在高侧分流任一端；动态测量须另选差分／合适电流采样方案，首轮不用它凑峰值。

### 5. 固定条件，按五个状态测

先用正常跳线确认现版启动、自然息屏、KEY1、BLE 连接正常，记固件身份。若进行完整阶段验收，仍要做 [Product 联合矩阵](PRODUCT-ACCEPTANCE.md#同一固件联合矩阵)；本次有界初测可先定位，不能因此宣布联合验收通过。

推荐首轮亮度 **50%**（做不到精确值就记实际值）、普通同一页面、相同内容；不用手电筒／呼吸动画作亮屏基准。记录息屏超时、勿扰状态；没有运行中的倒计时、近期闹钟或意外通知。保持手机距离／供电来源不变。为测亮屏可临时常亮，测完该行必须关闭，再等待自然息屏。原设置先记下，收尾恢复。

| ID／状态 | 怎样进入 | 等待与读数 |
|---|---|---|
| S1 亮屏、BLE 已连接、PM allow | 同一普通页面、固定亮度，临时常亮；确认手机连接 | 状态稳定后等 30s，再观察 60s，每 15s 抄一次，共 4 个读数 |
| S2 息屏、BLE 已连接、PM allow | 关闭临时常亮，不触摸，等自然黑屏 | 从黑屏开始等 30s，再按同样 60s／4 次记录 |
| S3 息屏、BLE 未连接、PM allow | 关闭手机蓝牙，确认板端断连，等自然息屏 | 同上；记“未连接／可能广播”，不把手机蓝牙关掉写成板端 BLE 关闭 |
| S4 息屏、BLE 未连接、PM hold | 先按 KEY1 亮屏，再用现有串口工具执行 `wf_pm hold`；停发命令，等自然息屏 | 同上；这是“黑屏但阻止 Deep”的对照，不是正常使用配置 |
| S5 息屏、BLE 未连接、PM allow 恢复 | 按 KEY1，执行 `wf_pm allow`，停发命令，等自然息屏 | 同上；allow 的一次性诊断在 5s 后发生，30s 等待将它排除在读数窗口外 |

整组重复 **3 轮**，每轮恢复手机连接再从 S1 开始。每个状态保留 4 个原始读数／显示变化范围；四个读数的算术均值仅是粗略显示均值，不是整段电流积分。若手机同步／Flash 保存／意外通知打断该分钟，标记原因并重新测该行，不悄悄删异常样本。负数先断电查方向；0 或很小读数先确认是否被跳线旁路以及仪表分辨率。

`hold/allow` 使用已有不触发 DTR／RTS 复位的串口方式，相关限制见 [PM 诊断](PM-EVENT-WAKE.md)。不要新开会自动复位的终端；深睡时串口不响应先按 KEY1，不能连续发送命令硬等。每个稳定窗口不发送查询。串口连接／输出条件在 S3–S5 保持相同；软件自发日志仍要记明，不能声称完全无 UART 活动。现场不能可靠发命令时先完成 S1–S3，S4–S5 明确未测。任何实际复位都记录，并重新确认 PM 状态，因为启动默认 allow。

### 6. 再观察三种事件是否回到息屏基线

恢复 PM allow、BLE 已连接和普通息屏；先记录一次 S2。依次做：**KEY1 唤醒再自然息屏；一条真实测试通知预览后息屏；一次 1 分钟倒计时到期提醒，关闭提醒后息屏**。每种先做一轮，异常再定位；闹钟可另加一行，记录原配置并在结束后恢复，不与倒计时同时触发。勿扰等设置影响是否亮屏，应按当前契约记录；电机仍未接，所以没有振动能耗。

对每次事件记：触发时间、是否亮屏、是否重启／BLE 掉线、最后一次息屏时间；息屏后第 30s、60s、120s 的表上读数与 S2 的同条件范围比较。120s 仍未恢复就写“观察窗内未恢复”，不要无限等到看似正常才报通过。普通表只报告可见变化及恢复趋势，**短脉冲峰值／单次事件能量均写未测**；显示最大值不等于真实峰值。若追加了动态仪器，另记采样率、量程、带宽、压降及积分窗口。

### 8. 收尾和如何决定下一步

结束前先恢复 `wf_pm allow`、原显示／勿扰／闹钟等设置，再断电；红笔移回 VΩ，恢复 7–8 原跳帽或转接短接塞，核对三对桥接并拍照。普通 USB 启动，确认显示、自然息屏、KEY1 和连接正常。电池线若已做，仍单独绝缘保存；不要因为当天顺利就追加充电。

- S4 与 S5 差异说明这套条件下 PM 放行是否减少该轨电流；不能仅凭计数证明它。差异小先查测量分辨率、旁路、驱动锁与周期唤醒，不能立刻认定芯片不省电。
- S1 与 S2 是整个显示状态变化的差额，包含 CPU／驱动／供电联动，不全归到 AMOLED。S2 与 S3 是连接及广播等实际状态的差额，不等于纯射频电流。
- 事件后长期回不到基线，优先定位未释放的亮屏／PM 约束或后台任务。初测通过后，再选一个问题优化并复测同一条件，随后补完整联合稳定性与更长的电流记录。
- 首轮结果足以开始讨论自制 PCB 的负载／接口，但投板前还要确定安全的电池供电／充电、PPG 在选定辅助板的电气与原始信号、屏幕接口、调试／测流入口和机械尺寸。辅助板实验不代替黄山派功耗；自制板也不自动消除软件唤醒耗电。续航须后续电池端能量或实际时长验证。

- [ ] 主板和外设全断电，先套好热缩管，再焊无源转接线、所需排母和可插拔外设线；检查焊桥、虚焊、裸露线丝，并逐根导通核对。只焊 H1 已确认的连接，不为省事把全部模块永久接死。

- [ ] 接头独立绝缘，热缩加热避开电芯和 FPC；外层增加应力固定，让拉力不落在焊点或电池引线根部。不能靠一圈胶带掩盖裸铜／尖刺，也不能加热、挤压电芯来适配尺寸。
- [ ] 再用 DC 电压档从最终电池插头测正负和电压，和主板插座照片逐项比对；空线束用通断档检查。保留焊前／焊后照片，确认金属碎屑清理后仍不接电池，等 H2 放行。

### H4 — 电池独立运行，再做受控充电

H2 以及 H1／H3 中电池、供电和本次测量路径的相关项目通过后，先在桌面执行；暂不接电机、PPG 或佩戴，外设待定项只阻断对应 H5 接入。限流电源预检只能按已审核的供电路径使用，不得与电池随意并联。

本段凡需串表，先按 [串表动作顺序](#ammeter-procedure) 操作，使用 H1 已核验的对应路径；电池独立供电记录流出电池的电流，充电记录流入电池的电流，注明表笔方向和正负号。

- [ ] 确认 USB 和其他可供电线均拔掉，仪表与测点符合 H1；接入电池做首次独立启动。记录电芯电压、输入电流／温度、显示、KEY1、BLE、短息屏恢复；异常立刻断开，先查接法和电压再重试。
- [ ] 如实读取电池电压／充电状态，与万用表交叉核对；不能由 500mAh 标称值直接产生百分比。测量／标定未完成的 UI 继续显示不可用，不将接电池等同电量显示已交付。
- [ ] 按 H2 验证过的接法开始首次充电，全程有人观察；同时核对电芯端电压、**流入电池的电流**及温度。USB 口总电流包含主板负载，不是电池充电电流。设置值、实际值和仪表误差分开记录，均不得突破对应电芯限值。
- [ ] 覆盖启充、稳定充电、接近终止／终止，以及屏灭／唤醒、USB 移除／重接和所选复位路径；台架先验证可能出现的越限窗口，再用真实电池确认。记录终止和再充条件，不能只看充电图标。
- [ ] 测 USB→电池和电池→USB 的真实切换，记录是否重启、RTC 是否保留、设置是否恢复。软件 reboot、KEY1、RTS 掉电和全断电分别命名；不承诺“有电池就一定跨 RTS 保时”。
- [ ] 首次低电量／运行终止实验遵守已核实的电芯与供电下限，到阈值停止并补电；不反复依赖保护板切断、不短接保护、不用深度放电测极限容量。

### H5 — 一次只增加一个外设

每次断开所有供电后接线，先独立检查，再进入 Product；诊断固件结果只算该模块证据。新负载通过后再叠加下一种，失败时恢复已通过的组合。

| 次序 | 操作清单 | 验收与退出 |
|---|---|---|
| 振动电机 | 按 H1 接板载驱动；固定转子外壳，限流条件下从短脉冲开始，记录启动／运行电流、驱动温升、关断；再接真实提醒 | 能启动并停止，无主板压降重启；通知／闹钟／倒计时与勿扰按各自契约工作。启动／堵转额定证据缺失时不靠强行卡转补测 |
| PPG 电气与原始信号 | 先供电／I²C 器件 ID，再红光／红外原始采样；检查遮光、静止手指、无手指，最后再评估腕部结构 | 有真实原始信号；缺失／无信号明确无效。不得把信号波形或演示数字称为心率／血氧精度通过 |
| PPG 任务退出 | 固件具备对应功能后覆盖正常、无信号、失联、取消、超时、最多一次重试和连续触发；故障注入按已审核方法，不带电拔线 | 结束后关 LED／采样并释放休眠阻塞；错误可恢复。先参考 [F411 复用评估](F411-REUSE.md)，不拆旧表或整搬架构 |
| 板载 IMU | 核对器件 ID、坐标方向、采样/FIFO/中断和停采样；C2 使用其自己的分支／版本验收 | 手持触发、腕部姿态、漏触发／误触发和禁用边界分别记录；未合入 C2 不能在主线默认有抬腕功能 |
| 光感／基础计步等后续项 | 按已确定产品范围另开小实验；光感先读值，再考虑自动亮度；计步需真实计数对照 | 不阻塞电池最小闭环；不因板载有地磁／音频而新增指南针或音频任务 |

- [ ] 每项保留“断开该模块”的对照，记录新增电流、资源和线束；外设故障不应无限重试或让退出失效，完成才更新对应专题的硬件结果。

### H6 — 先测稳定状态，再测事件能量

开始前复核选定同版的联合稳定性。新模块或新固件改变结果时补相关回归；未通过的项目保留原因，不以测量取代修复。测流必须有记录到 H1 表里的实际接线图。

<a id="ammeter-procedure"></a>
**串表动作顺序**：断开全部供电 → 照片记录原跳线 → 只打开选定的一条测量路径 → 按仪表说明插 COM／对应电流插孔、从能承受峰值的高量程开始 → 电流表串接电源侧与负载侧 → 检查没有并联短接或旁路 → 通电观察。换档／换插孔／改线先断电。测完断电，恢复原跳线，**红表笔插回 VΩ**，拍照确认并做一次普通启动。

电池整机测量时拔 USB；外接串口、调试器或其他线可能供电、旁路或改变休眠，应断开或使用已经核验的隔离方式。需要日志时另做带仪器的对照，不能把 USB 供电数据写作电池续航。测 VSYS／3.3V 只代表该轨，不可把有上下游包含关系的电流直接相加。

| 状态／事件 | 固定条件和记录 | 合适的证据 |
|---|---|---|
| 屏亮静态与实际操作 | 固定亮度、页面内容和动画；分别注明静止／交互 | 稳定读数、持续时间、范围；操作动态另记 |
| 屏灭未连接／屏灭已连接 | BLE、传感器、日志、临时常亮均有记录；注明进入状态后的等待时间 | 分别重复测量，记录变化范围；不是看到黑屏就宣称深睡 |
| KEY1／真实通知／闹钟／倒计时 | 事件前、事件过程和恢复段，含实际提醒负载 | 能捕捉脉冲的电流采样／分流加示波器或合适记录仪，积分得到每次能量 |
| PPG／振动／IMU | 固定周期、占空比、采样率，分别做开启和关闭对照 | 模块增量和退出后的恢复；避免重复计入总量 |
| 整个负载周期 | 电池端电压随时间、同版固定使用模式 | 电池端能量积分及实际运行时长；分轨结果用来定位耗电 |

- [ ] 每个稳态在相同条件下至少重复三次，记录范围和仪表压降。低量程造成复位、读数跳变或明显改变 BLE／睡眠行为时停测，恢复接线，改合适仪表／量程，不把扰动后的结果当正常功耗。
- [ ] 只有万用表时先交付稳态表；短脉冲峰值和能量标“未测”，不从屏幕刷新读数猜峰值。动态测量的采样率与量程需足以覆盖事件，注明带宽／分流压降及误差。
- [ ] 续航比较沿用 [固定负载](BASELINE.md#功耗比较条件)：每日 45 分钟亮屏、30 次通知（5 次打开）、日常 BLE、关闭常亮显示、记录心率采样配置。未实现的负载标缺项，不虚构 PPG 运行。
- [ ] 跨电压轨按能量计算：`E_day = ∫ V_bat(t) × I_bat(t) dt`；初步预计天数为可用电池能量／日均能量，注明容量来源与 20% 预留。300mAh 是原比较基准，实购标称 500mAh 另列；均不替代实测容量或实际续航。
