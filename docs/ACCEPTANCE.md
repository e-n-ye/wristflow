# 硬件操作清单与验收

<a id="hardware-sequence"></a>
## 2026-10-14 硬件工作的一次性准备与分段验收

用户在 10-13 要求把电池接线、焊接、功耗测量等需要实物参与的工作按操作流程整理；10-14 从前序聊天接续完成本清单。这里保存操作契约和记录模板，**活动项与唯一下一步仍在 [STATUS](STATUS.md#current)**，不是要求现在执行全部步骤。目标、预算和 12-21 期限沿用 [BASELINE](BASELINE.md)，未新增采购或改变产品范围。

已知起点：通知归组与历史经 [PR #55](https://github.com/e-n-ye/wristflow/pull/55) 合入 `6997ded`，已有 USB 下有界验收；最新记录仍为同一黄山派和屏幕、USB-only、无新增接线。电池、电机、PPG 和线材已到手，但标签、连接器、极性、仪表型号尚未核实。**“已到手”“有源码”“编译通过”“实物通过”分别记录。** 本清单没有执行接线、刷机或测量。

### 怎样安排

可以集中借工具、拍照盘点、画接线表、准备线束；通电时每次只新增一种负载。充电配置未核实就停在准备阶段，不能为了同一天做完而跳过。充放电观察和连续一周试戴需要后续时间。

| 顺序 | 本段交付物 | 到哪里才能继续 |
|---|---|---|
| H0 物料与工具 | 照片、型号、缺项表 | 能辨认实际硬件和仪表能力 |
| H1 断电核线 | 对应实物的接线表、跳线照片 | 本次接入的极性、电压、测点无空白或冲突；其他模块各自待验 |
| H2 软件与供电前置 | 同版 USB 联合结果、充电控制方案和验证证据 | 安全参数先于充电启用，启动／复位／唤醒均成立 |
| H3 焊接与绝缘 | 电池转接线、排母、可独立插拔的外设线束 | 逐根导通、无焊桥、极性复核和固定通过 |
| H4 电池与充电 | 电池独立供电、受控充电、切换记录 | 无越限、异常发热、意外复位；参数有实测依据 |
| H5 逐个外设 | 电机、PPG、板载传感器各自验收 | 电气兼容且可正常启停／退出 |
| H6 电流与能量 | 同版、同条件的分状态测量表 | 测量路径有效，稳态与动态证据分开 |
| H7 整机与记录 | 组合功能、RTC、存储及机械验收 | 桌面集成通过后才能贴肤 |
| H8 试戴与续航 | 短时试戴、连续一周记录和路线结论 | 实际运行、补电、故障均可追溯 |

H2 的固件核验可与 H3 的无源线束准备并行；电池引出线处理仍须先完成 H1。每段失败只回到该段排查，不同时换固件、换线和换供电。

### H0 — 先把东西和工具放齐

|---|---|---|
| 黄山派、屏幕、FPC、跳线帽 | 已用于 USB 验收 | 主板／屏幕板丝印与版本、充电 IC 实装、FPC 方向和扣锁；正反面清晰照片 |
| LP902030 电池 | 采购页 3.7V、500mAh、带保护、无插头引线 | 标签和批次、外观、尺寸；数据页充电截止 4.2V、最大 250mA 是否对应实物；允许温度／放电下限 |
| GH1.25 2P 线、1.27mm 双排排母、红黑线 | 已到手 | 键位／间距／插合方向、线序及线径，不能凭红黑颜色判极性 |
| MAX30102 绿板、1027 两线转子电机 | 已到手 | 模块正反面和引脚标识／原理图；电机额定条件与驱动允许电流 |
| PI 胶带、热缩管、弹力带、固定件 | 已到手 | 尺寸够用，无裸露尖角；电芯不会受压、被螺钉顶到或被导线拉扯 |
| 万用表和表笔 | 可借，型号未核实 | DC 电压、带保险丝的电流档、量程、分辨率、精度、负担电压与表笔插孔；记录型号／说明书 |
| 焊接工具 | 尚无到手记录 | 可调温烙铁、支架、焊锡／助焊剂、吸锡工具、剥线钳、镊子、放大检查、通风和耐热绝缘工作面 |
| 限流电源、温度测量、动态测量设备 | 是否可用待核实 | 首次负载／充电核验所需仪器；普通台式电源不默认能吸收充电电流，不能直接充当电池模拟器 |

- [ ] 拍照并填写缺项，工具优先借用；本清单不下单、不联系卖家。万用表未核实前，可以盘点，不能开始接电池或串表测流。
- [ ] 先用废线练习剥线、预上锡、焊接和热缩绝缘，确认能做出不松动、无尖刺的接头。首次处理锂电引出线宜由有经验的人现场协助。
- [ ] 明确退出方式：电源接头随手可断开，桌面无可导电散件；异常发热、异味、鼓包、冒烟或电压／电流越限立即停止，不继续试充，不佩戴。

### H1 — 全部断电后核对接线

先拔 USB、外部电源并使电池与主板分离；**电池自身仍有电**。不带电插拔 FPC、移动跳线或改焊点。通断／电阻档只测无源线束和确认断电后的电路，不跨接电芯。

- [ ] 对照 [HARDWARE 的官方资料与版本差异](HARDWARE.md#版本与机械证据)，把照片上的 PCB、充电 IC、连接器逐项对应到原理图。旧 Wiki 的 SY6103 与现资料的 AW32001 不能混用；EPRO 文件名 V1.2 也不能代替 sheet／实装核对。
- [ ] 用 **DC 电压档，黑笔 COM、红笔 VΩ** 测电池开路电压和极性，记录数值；插头以“从插合面看、锁扣朝某方向”的照片标记正负。绝不把电流档表笔直接跨在电池两端。
- [ ] 无源线束逐根测导通、相邻端子不短路；连接器能匹配再使用，不硬塞、不直接把单节锂电接到 3.3V 引脚。
- [ ] 标出 VBAT、VSYS、VCC_3V3 各自对应的实际跳线和测量范围；标出 USB／调试器／其他地线可能形成的旁路。下方历史的 5-6、7-8、11-12 只作设计资料提示，未经实物对应不得照号拔帽。
- [ ] PPG 必须确认 VIN、GND、SDA、SCL、INT 的实际引脚、主控 IO 电平、模块稳压／电平转换、上拉电源、地址与断电反向供电。商品写“1.8–5V 供电”不证明信号能接 5V；PA39/40 的示例也不是实物接线图。
- [ ] 电机必须对应板载驱动输出和供电，不接 MCU GPIO 直接带负载；额定、启动电流和驱动上限未齐时先不通电，不用人为堵转来猜极限。

接线表由核验后填写；任何“待定”保留为空并阻断对应接入，不由文档补猜针脚：

| 对象 | 主板连接器／引脚／照片标记 | 对端引脚 | 电压／极性／电流上限 | 证据与复核 |
|---|---|---|---|---|
| 电池正负／插头方向 | 待核实 | 待核实 | 实物电芯规格及实测 | 待填 |
| 电机驱动输出 | 待核实 | 待核实 | 驱动与电机共同允许范围 | 待填 |
| PPG 供电、地、SDA、SCL、INT | 每根单列，待核实 | 待核实 | 模块供电与 IO 分别填写 | 待填 |
| 电池测流／VSYS／3.3V | 每条轨单列，待核实 | 电源侧／负载侧 | 预计峰值、仪表档位和压降 | 待填 |

### H2 — 接电池前由软件和台架先消除阻断

主代理准备可审阅的软件与试验方案，用户配合实物观察；本清单不修改固定 SDK，不提供未经验证的寄存器写入命令。

- [ ] 选定本次 Product 提交和镜像哈希，先按 [Product 同版矩阵](PRODUCT-ACCEPTANCE.md#同一固件联合矩阵) 做 USB 基线：10 轮导航、10 轮息屏／KEY1、5 次重连、真实通知及 30–60 分钟连续观察。通知部分沿用 [现行契约](NOTIFICATION-UI.md#notification-groups)：手机清通知栏与 QQ 精确撤回分开；同 ID 更新无法制造就保留未覆盖，不能把不同 ID 的新消息替代它。旧冻结版本、旧设置回退授权不自动沿用到新实验。
- [ ] 核对实装充电 IC 数据手册、上电默认值、使能电平、充电电压／恒流／预充／终止设置、温度保护条件。按电芯规格与芯片误差选保守值；采购页 4.2V、250mA 是上限，不能把“请求 250mA”当成可靠限流。
- [ ] 解决上电、初始化、USB 插入、复位、休眠恢复及错误恢复时的充电启用顺序；必须在电池可能被充电之前建立有效限制，通信失败保持禁充。仅在应用启动后补写参数不能证明启动窗口安全。
- [ ] 以原始寄存器、独立解码和仪表核验限制与读写失败处理。先在适配的可吸收电流台架／电池模拟条件下检查，记录接法与限流；无合适工具时先完成方案，暂不接真实电池充电。空载测一个 BAT 电压不足以证明恒流／终止行为。
- [ ] 实施若改变固件，按 [BUILD](BUILD.md#当前机器直接使用) 构建和核对产物，再独立按 [FLASHING](FLASHING.md#current-flash-entry) 处理下载。成功编译、写入 verify 与充电实测各有记录；新版本补齐受影响的 USB／PM 回归。

本轮源码核验的承重证据，固定 SDK 提交以 [锁文件](../sdk.lock.json) 为准：

| 证据 | 含义与待验证边界 |
|---|---|
| [aw32001.c:381–403](https://github.com/OpenSiFli/SiFli-SDK/blob/421126d9f476ed8e2a6f0b0ca28a9f241c182e65/customer/peripherals/charger/aw32001/aw32001.c#L381) | 初始化可能先开启充电、延迟 50ms，再请求 4215mV，且没有显式设恒流；4215mV 能被 15mV 步进精确编码，不等于 4200mV |
| [aw32001.c:160–211](https://github.com/OpenSiFli/SiFli-SDK/blob/421126d9f476ed8e2a6f0b0ca28a9f241c182e65/customer/peripherals/charger/aw32001/aw32001.c#L160) | 电流写入 `set_chg/8`，同函数的旧值解码却为 `(code+1)*8`；按其公式请求 250 会对应 256mA，仅为源码推算。电压 getter 使用有符号字节右移，须核验原始寄存器，不能只信打印值 |
| [bsp_power.c:36–88](https://github.com/OpenSiFli/SiFli-SDK/blob/421126d9f476ed8e2a6f0b0ca28a9f241c182e65/customer/boards/sf32lb52-lchspi-ulp_base/bsp_power.c#L36) | 深睡恢复路径有清 CEB 启用充电；需核对所选 Product 的实际编入路径和配置保持，不只测试冷启动 |
| [bsp_lcd_tp.c:24–76](https://github.com/OpenSiFli/SiFli-SDK/blob/421126d9f476ed8e2a6f0b0ca28a9f241c182e65/customer/boards/sf32lb52-lchspi-ulp_base/bsp_lcd_tp.c#L24) | 屏幕、3.3V、充电 I²C 和音频 PA 存在联动；黑屏不是整板低功耗或充电配置保持的证据 |

这些事实足以阻止直接沿用旧 USB 固件充电，但尚未证明当前板上实际电流、芯片默认值或各路径均被执行。详细既有约束见 [采购审核](PURCHASE-REVIEW.md#到货后接入条件)。

### H3 — 集中做线束、焊接与绝缘

- [ ] 主板和外设全断电，先套好热缩管，再焊无源转接线、所需排母和可插拔外设线；检查焊桥、虚焊、裸露线丝，并逐根导通核对。只焊 H1 已确认的连接，不为省事把全部模块永久接死。
- [ ] 电池如果需要接 GH 尾线，只处理成品电池已有引出线与尾线的接头，远离电芯；不直接焊电芯／极耳，不拆保护板。两极分别绝缘，每次只暴露并连接一极，完成绝缘后再处理另一极；不得同时剪两根电池线。无法可靠操作时交由有经验者完成这一步。
- [ ] 接头独立绝缘，热缩加热避开电芯和 FPC；外层增加应力固定，让拉力不落在焊点或电池引线根部。不能靠一圈胶带掩盖裸铜／尖刺，也不能加热、挤压电芯来适配尺寸。
- [ ] 再用 DC 电压档从最终电池插头测正负和电压，和主板插座照片逐项比对；空线束用通断档检查。保留焊前／焊后照片，确认金属碎屑清理后仍不接电池，等 H2 放行。

### H4 — 电池独立运行，再做受控充电

H2 以及 H1／H3 中电池、供电和本次测量路径的相关项目通过后，先在桌面执行；暂不接电机、PPG 或佩戴，外设待定项只阻断对应 H5 接入。限流电源预检只能按已审核的供电路径使用，不得与电池随意并联。

本段凡需串表，先按 [串表动作顺序](#ammeter-procedure) 操作，使用 H1 已核验的对应路径；电池独立供电记录流出电池的电流，充电记录流入电池的电流，注明表笔方向和正负号。

- [ ] 确认 USB 和其他可供电线均拔掉，仪表与测点符合 H1；接入电池做首次独立启动。记录电芯电压、输入电流／温度、显示、KEY1、BLE、短息屏恢复；异常立刻断开，先查接法和电压再重试。
- [ ] 如实读取电池电压／充电状态，与万用表交叉核对；不能由 500mAh 标称值直接产生百分比。测量／标定未完成的 UI 继续显示不可用，不将接电池等同电量显示已交付。
- [ ] 按 H2 验证过的接法开始首次充电，全程有人观察；同时核对电芯端电压、**流入电池的电流**及温度。USB 口总电流包含主板负载，不是电池充电电流。设置值、实际值和仪表误差分开记录，均不得突破对应电芯限值。
- [ ] 覆盖启充、稳定充电、接近终止／终止，以及屏灭／唤醒、USB 移除／重接和所选复位路径；台架先验证可能出现的越限窗口，再用真实电池确认。记录终止和再充条件，不能只看充电图标。
- [ ] 测 USB→电池和电池→USB 的真实切换，记录是否重启、RTC 是否保留、设置是否恢复。软件 reboot、KEY1、RTS 掉电和全断电分别命名；不承诺“有电池就一定跨 RTS 保时”。
- [ ] 首次低电量／运行终止实验遵守已核实的电芯与供电下限，到阈值停止并补电；不反复依赖保护板切断、不短接保护、不用深度放电测极限容量。

### H5 — 一次只增加一个外设

每次断开所有供电后接线，先独立检查，再进入 Product；诊断固件结果只算该模块证据。新负载通过后再叠加下一种，失败时恢复已通过的组合。

| 次序 | 操作清单 | 验收与退出 |
|---|---|---|
| 振动电机 | 按 H1 接板载驱动；固定转子外壳，限流条件下从短脉冲开始，记录启动／运行电流、驱动温升、关断；再接真实提醒 | 能启动并停止，无主板压降重启；通知／闹钟／倒计时与勿扰按各自契约工作。启动／堵转额定证据缺失时不靠强行卡转补测 |
| PPG 电气与原始信号 | 先供电／I²C 器件 ID，再红光／红外原始采样；检查遮光、静止手指、无手指，最后再评估腕部结构 | 有真实原始信号；缺失／无信号明确无效。不得把信号波形或演示数字称为心率／血氧精度通过 |
| PPG 任务退出 | 固件具备对应功能后覆盖正常、无信号、失联、取消、超时、最多一次重试和连续触发；故障注入按已审核方法，不带电拔线 | 结束后关 LED／采样并释放休眠阻塞；错误可恢复。先参考 [F411 复用评估](F411-REUSE.md)，不拆旧表或整搬架构 |
| 板载 IMU | 核对器件 ID、坐标方向、采样/FIFO/中断和停采样；C2 使用其自己的分支／版本验收 | 手持触发、腕部姿态、漏触发／误触发和禁用边界分别记录；未合入 C2 不能在主线默认有抬腕功能 |
| 光感／基础计步等后续项 | 按已确定产品范围另开小实验；光感先读值，再考虑自动亮度；计步需真实计数对照 | 不阻塞电池最小闭环；不因板载有地磁／音频而新增指南针或音频任务 |

- [ ] 每项保留“断开该模块”的对照，记录新增电流、资源和线束；外设故障不应无限重试或让退出失效，完成才更新对应专题的硬件结果。

### H6 — 先测稳定状态，再测事件能量

开始前复核选定同版的联合稳定性。新模块或新固件改变结果时补相关回归；未通过的项目保留原因，不以测量取代修复。测流必须有记录到 H1 表里的实际接线图。

<a id="ammeter-procedure"></a>
**串表动作顺序**：断开全部供电 → 照片记录原跳线 → 只打开选定的一条测量路径 → 按仪表说明插 COM／对应电流插孔、从能承受峰值的高量程开始 → 电流表串接电源侧与负载侧 → 检查没有并联短接或旁路 → 通电观察。换档／换插孔／改线先断电。测完断电，恢复原跳线，**红表笔插回 VΩ**，拍照确认并做一次普通启动。

电池整机测量时拔 USB；外接串口、调试器或其他线可能供电、旁路或改变休眠，应断开或使用已经核验的隔离方式。需要日志时另做带仪器的对照，不能把 USB 供电数据写作电池续航。测 VSYS／3.3V 只代表该轨，不可把有上下游包含关系的电流直接相加。
