# 长续航模式

2026-10-22软件轮，起点`9836b21`。范围由[用户共识](BASELINE.md#endurance-20261022)限定；活动项和唯一下一步见[STATUS](STATUS.md#current)。参考照片只提供视觉层级，不证明本设备具备心率、血氧、NFC或可用天数估算。

## 操作与恢复

- 控制中心短按长续航，确认后进入；长按打开电池页。电池页向上滚动可进入长续航设置、续航优化和说明。共用确认组件只改变文字和接受动作。
- 极简黑底页显示本地日期、时分、电压估算电量和实际有效步数；未校时／无步数来源分别显示`--`，有效零步显示0。沿用用户亮度和普通自动息屏时长，不常亮。
- KEY1同次持续按住3秒显示退出环，黑屏先唤醒并继续累计；提前松手取消。提醒打断该次按住，关闭提醒后需重新按。新按压编号可识别同步间合并的松手／重按；退出按压的CLICKED被平台抑制。
- 进入时已经USB有效不会立即退出。只有先确认PG无输入、再确认有输入才退出；未知PG不能制造拔线。USB唤醒入口和普通快照均核对同一规则。退出回正常表盘。
- v10／24B记录的byte13 bit6保存模式，v9及更旧受支持格式迁移为关闭；原偏好不被覆写。已确认写入后普通重启仍进模式，旧固件不保证读新记录。保存失败保留RAM选择并显示失败，退出后可在设置重试；不声称断写原子性。

## 服务边界与所有权

保留RTC、LSM6DS3TR-C既有原生计步、闹钟配置／日历服务、运行中倒计时、提醒仲裁、存储及充电安全worker。现成硬件路径及证据见[硬件能力](HARDWARE-CAPABILITIES.md#native-wrist-wake)，不新增自研计步或腕算法，不改SDK锁、IMU参数或充电控制。提醒正常呈现／关闭后回极简页，模式会话不因120秒长睡回普通表盘。

`core/endurance`持有USB资格和三秒按压；shell拥有模式导航、显示和临时常亮暂停，apps及`endurance_view`绑定页面，XML经官方Pro导出。main将模式派生为BLE／腕服务的实际请求；UI不直接操作总线。原IMU worker关闭腕路由／IRQ并保留计步，缓存区分已暂停与失败。

BLE暂停关闭连接和广播，`is_auto_restart=0`，恢复复用同一服务和广播context。锁定SDK的`ble_power_off()`为空实现，因此本轮不声称关闭蓝牙芯片电源。`radio_policy`区分观察态、在途动作、相关回调revision、固定超时与拒绝；异步回调取代旧命令结果，故障证据保留，迟到活动仍得到有限安全关闭尝试，同一拒绝事实不忙重试。初始化前等待不算已提交操作超时。`wf_ble radio`只读缓存诊断，不操控设备。

暂停边沿在phone mutex内与解析／TX提交串行，递增持久epoch；RX入口捕获连接代次和epoch。控制消息丢失或快速关闭再开启不丢暂停屏障，worker处理数据前清半帧／回复意图，旧epoch数据被丢弃。通知历史RAM保留；保守丢包允许，旧半帧不能拼接到恢复后的协议。SDK底层停止提交失败可能留在STOPPING，当前明确显示失败并允许用户退出，不承诺自动恢复。

临时常亮保存原始开始及期限，模式中暂停，退出时仅在原截止时间未到才恢复；不重新赠予完整时长，重启不恢复此临时状态。续航优化仅列当前开启的抬腕、临时常亮并逐项关闭；无项时说明暂无可关闭项，不伪造节省小时、心率／血氧开关或优化评分。
