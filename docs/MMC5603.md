# MMC5603NJ 地磁硬件跑通

<a id="diagnostic-20261024"></a>
## 本轮范围与能力选择

用户在自动亮度PR #139交付后选择地磁，按[板载资源顺序](BOARD-RESOURCES.md)只推进第一个闭环：限时身份／原生自检／XYZ新帧、静置及旋转响应、停止和共享资源检查。当前状态与下一步仍只看[STATUS](STATUS.md#current)。本轮不制作指南针页面，不提供磁北／真北角度，不做软硬铁校准或倾斜补偿。

板载资料列MMC5603NJ，固定地址0x30、Product ID寄存器0x39／期望0x10；I2C3／PA39、PA40及共享PA30沿用现有传感器worker。器件内置20位测量、SET／RESET、Auto_SR、自动自检及连续测量；本轮选择**原生自动SET／RESET＋软件显式单次触发**，约每秒取得一帧，不启连续模式或IRQ。原生自检按手册执行，项目只负责限时、有效性和停止，不替代硬件检测。

SDK `mmc56x3.c`的I2C事务写在`RT_ASSERT`中，关闭断言会把事务一起移除，开启时失败会进入断言；包装器的PowerDown分支无实际停机、自检返回不支持，读数据不检查DONE。故仅参考寄存器／解码，在项目适配层实现可返回错误的有限状态机，不改锁定SDK或厂商源码。compass示例的I2C2和直接atan2不搬入当前Product。

## 命令、期限与所有权

`wf_mag start <1..120秒> | stop | status`。命令只预约／取消，status只复制短临界区缓存，不做I2C。默认不开启地磁，不新增主线程启动采样、页面、线程、timer或保存偏好。

`start`成功入队后立即置busy，拒绝重复及有限腕／LTR诊断交叉抢占；常驻IRQ腕和真实自动亮度可以在同一worker串行运行，不修改它们的请求、模式、代次或用户偏好。独立固定0x30适配器不修改IMU地址；PA30始终只拉高、不在退出时断电。全局日常stop／retry会先清理地磁，地磁清理未确认时不重建日常计步基线。

会话原截止包含准备、局部复位、自检、等待及采样，I/O后再次检查取消／截止，过期帧不发布。只有本次触发前DONE=0、触发后DONE=1、完整9B读取且DONE已清除才接受；任一通道0或0xFFFFF保守标饱和，counts与有效性分开。`sampled_ms`是软件读完观测时间，没有芯片硬件时间戳。50ms是“观察时仍无DONE”的逻辑等待截止；单次完成帧不会被下一次测量覆盖，若worker因已有事务延后观察，DONE在原会话截止内仍有效，不承诺50ms最大数据年龄。同步I2C沿现有50ms配置，逻辑期限不能中断正在执行的总线事务。

由于控制寄存器只写，停止通过器件局部复位建立已知默认基线：复位ACK→至少20ms→ID及OTP_ready→排空残余DONE→再等20ms确认无新DONE。`stopped=1`仅指该有界确认，不叫任意原配置恢复，不等于功耗测量。读写或确认失败保留owned及共享IDLE责任，不后台循环重试，显式`stop`／日常恢复命令才尝试清理；未清理前拒绝新有限诊断。正常到期、取消或故障后无新增地磁采样。

**首轮设备结果（2026-10-24，有界失败）**：精确`5eb28e3c…`三镜像write＋verify成功，启动校时／原设置／计步检查点108／已保存腕恢复。用户按要求平放静置，窗口先确认ID`0x10`、I/O错误0；原生自检读到工厂`63/7a/72`、实现取80%向下`4f/61/5b`，触发后状态`0x75`含Sat_sensor，报告失败，程序在自检后停止，未发布XYZ。停止基线`owned0／stopped1／after_status0x10`确认；自动亮度同窗仍有效、无fault／cleanup，计步／常驻腕保留。串口关闭后用户确认末态正常、临时常亮关闭、原设置保留。完整[设备证据](evidence/2026-10-24/mmc5603-hardware.json)保存失败UART、前态、下载及收尾。

该失败只证明本次程序化自检报告`Sat_sensor=1`；身份通信和停止基线通过，不能证明芯片损坏、阈值编码错误或磁测量能力不足。Rev.B p10–11没有工厂字节的符号／偏置128／绝对值说明，p14只写“80% of data readout”；SDK没有实现自检。当前不改阈值、不继续旋转、不进入指南针页面，先补权威资料／协议核查。XYZ、轴向、校准航向、显式stop／到期物理结果、功耗及长期稳定性仍未验。
