## 一次集中拍摄：照片与演示顺序

用户已表示可以配合提供素材。本轮是宣传素材拍摄，沿用板上现有固件和已有UI入口；不需要重新下载、复位、校时、串口采集或新设备验证。采用一份人工短清单即可，不新增协作页或采集脚本；照片／视频说明不提升既有硬件验收结论。

### 拍摄准备

- 手机横向拍摄短视频，建议1080p／30fps；关闭美颜／滤镜，擦净镜头与屏幕，采用柔和侧光，避开灯和手机在屏幕上的反光。
- 固定手机和手表，尽量让屏幕正对镜头，点击屏幕锁定对焦／曝光；亮度以文字清楚且不过曝为准。照片保留全分辨率原件。
- 保持原供电和固定接线，拍摄时不拆线。整机与开发板／接线的照片分开拍，用户不必为画面临时断电或改接。
- 使用无个人信息的页面；暂不拍真实聊天通知、手机账号或设备标识。缺数据的`--`、估算符号和未校准提示按实际保留。
- 素材随附拍摄日期及板上版本；按当前单线最新固件使用，不重新询问版本偏好，也不把主线工具提交号当作板上BIN。板上版本未知则标未知。
