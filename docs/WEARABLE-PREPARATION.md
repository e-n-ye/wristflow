# 可佩戴工程样机准备与分级验证

2026-11-03规划轮，源码／文档基线`c1b761c`。本页保存外壳调查、采购筛选和验证契约，不维护活动队列；实际下一步只见[STATUS](STATUS.md#current)。本轮没有创建PCB工程、修改固件／SDK／充电参数、接线、烧录、测流、试戴、下单或联系卖家。下列建议不是已经通过的硬件结论。

## 本轮输入与路线判断

用户希望先为长期佩戴准备外壳、喇叭及表带；喇叭优先放进外壳，能清楚听见提醒即可。用户报告现板为**V1.1**，尚未分别核对核心板／屏幕板丝印、装配差异和充电IC；先前官方V1.2工程证据仍不能当作该实物的精确图纸。电池沿用原ZCLP500记录，新增照片可辨`902030 / 3.7V`；按型号惯例推断名义约9×20×30mm，照片正面约20×30mm，但没有厚度、公差、保护板和出线最大包络实测。不能从商品图片认定实物保护或更换电池身份。

**建议先走路线A的尺寸核验与一套试打印。** 它能较快验证佩戴负担及固定方法，尚不能直接进入长期佩戴。路线B只做架构候选：在A实测显示厚度、固定、天线、热或功耗问题由开发板结构造成且难以修正时，再决定自定义板是否必要。当前没有这样的充分证据，不以缺NFC／GNSS／PPG为由自动扩大首版；Redmi参考不变成现板能力承诺。

**打印准入**：取得文件，确认单位／缩放为设计值和零件完整性，以实物或尺寸包络核基本孔位及电池／喇叭候选。可先打一套用于离腕尺寸验证，先空壳／无电仿形件试装，再放断电实物；不能强行合盖。必要时先打表带接口试片，不能整体缩放壳体来补公差。打印服务需给出材料、方向／支撑、后处理和报价；作者PETG配置作为起点，不是对表耳强度的保证。切片不得直接运行来源不明的机器G-code。

## 最低成本功耗下一轮（先准备，设备操作另开有界窗口）

### 先使用已有实验，不再重复深放电

- [10/30–31三场景](BATTERY-ESTIMATE.md#runtime-scenes-20261030)：普通页亮度50、手电筒100、OFF各约900秒，辅助电压分别4157→4143、4120→4050、4100→4095mV。不同起点和日期，OFF是亮屏／唤醒两端，不能用下降幅度排名耗电。
- [11/02固定白屏](BATTERY-ESTIMATE.md#cycle-low-end-20261102)已有2538个新鲜BAT样本、3小时31分25秒、4142→3601mV；[低压末条](BATTERY-ESTIMATE.md#low-voltage-end-20261102)3240mV且无END，准确失效时刻未知。低压诊断持MCU IDLE、约5秒采样并逐条sync，含OFF记录；不是正常待机。
- [11/03曲线](BATTERY-ESTIMATE.md#usable-curve-20261103)是固定负载可用时间近似，充放电共表、充电粗估，非静置OCV／电流／容量标定。当前保留CycleLog测试版不等于低压模式仍ARM；测流前明确是否已停止实验，**不再arm-low，不为省电关闭正常使用功能，不把实验负载混入日常基线**。

### 测量边界先于读数

下表是[官方V1.2图纸调查](HARDWARE.md#meter-adapter-20261017)，不是V1.1现板的即刻接线图。硬件伙伴需先核V1.1实际网路、pin1／接合面、旁路和转接通断；未闭合时优先评估电池连接器的可拆成品串流线束，不带电探针猜测。

| 入口 | 能回答什么 | 不能当什么 |
|---|---|---|
| 电池单根正线的可靠串表／合适已调零直流钳表 | BAT-only、全部其他供电断开时的电池端整机电流；USB同接时是有符号的净充放电 | USB同接时不能当负载电流；旧钳表约200mA证据不证明µA级能力 |
| CN3 5–6 | 设计中的电池BAT支路净充放电 | 电池侧D18漏电不经过，不能称完整电池自耗；V1.1须核映射 |
| CN3 7–8 | VSYS下游，用于支路定位 | 不含CH340／USB上游等，不能当整机电池电流 |
| CN3 11–12 | 部分VCC_3V3负载 | 不含所有3.3V负载，电机／RGB另轨；三组具有上下游关系不能相加 |
| USB表 | USB输入电流／功率的粗观测 | 不等于电池消耗／充电电流，不能用来算BAT续航 |

先核仪表说明书：DCA档位、分辨率和误差、刷新／积分方式、额定／峰值／时限、保险及输入孔、负担电压／分流电阻。未知峰值从可承受启动／唤醒的较高固定档开始，µA档不能直接承担整机启动；不能在带电状态换孔／改线／切档。电流档仅串在已核支路，不能跨电池／电源两极；电池本体不用通断档。用可靠固定连接，不手持粗笔尖压1.27mm针脚。

最低成本一次小闭环：先借合适DMM及接触温度计，借第二表核串流总压降／负载端电压优先于购PPK2；成品线束离板通断及极性闭合后，选**BAT-only、正常模式**，USB／UART／其他供电断开，版本与电池电压范围记录。按真实偏好保留BLE／抬腕／自动亮度／AOD，记录现场照度和手机距离；固定亮度／关闭功能只用于另列的诊断对照，不能代替日常配置。

首组先比较同页面稳定亮屏与自然OFF：每态稳定30秒后连续60秒每15秒记读数／范围，做3个有界往返且检查恢复。普通页／白屏可作第二组明确固定亮度诊断；自动亮度AOD另列实际场景。有人按KEY／收到通知的污染窗口标注事件，不能静默删掉峰值来“平均”。不在测流中插USB取日志；用既有低频记录，回连后导出并注明回连改变边界。不要为读电压临时唤醒后冒充OFF电压。

如果量程／负担电压使设备复位、亮度／连接改变，结果无效，先恢复原接法，不归因软件耗电。第二表测整个表线／夹具路径压降及负载电压；单表分次测只能标不同时间，不能冒称同步。可记录`I×V`作为该边界稳态功率近似，但不凭这些离散读数推确定日常续航。

数据标签统一：`稳态离散读数`／`有波动仅供趋势`／`低于本档分辨率（非0）`／`过载或测量扰动，作废`／`未测`。DMM刷新间隙的BLE尖峰、启动／唤醒／音频／电机瞬态和未满足误差条件的µA级数值都写**未解析／未测**；MIN/MAX不自动等于真实峰值，OFF也不自动等于DEEP。

PPK2到手后优先捕获：①正常OFF整段，查周期唤醒和实际基线；②KEY／抬腕→亮屏→自然OFF恢复；③BLE连接／广播／通知／出入范围重连；④已有保存检查点；⑤单独音频和电机启动／停止，再评估组合峰值。以相同供电边界与真实偏好记录动态积分、最大值及窗口平均，对齐既有事件；不先改配置追求好看曲线。[Nordic说明](https://www.nordicsemi.com/Products/Development-hardware/Power-Profiler-Kit-2)区分电流计与电源模式，首次按官方指南和现板拓扑审定接入；不能当成可吸收充电电流的电池模拟器或接上就开始双向充电实验。

## 人类负责人怎样用最少阅读作工程判断

协作规则沿用用户要求：AI自主完成可自动验证的常规任务；高风险变更先给约束／影响／验证线，未验证风险继续保留。人类每轮只需处理具体的实物确认、真实体验和新取舍，不要求重学整库。

三份英文材料的实用提炼（意译，不是要求引入框架）：

- [Kief Morris发表于Martin Fowler网站的文章](https://martinfowler.com/articles/exploring-gen-ai/humans-and-agents.html)：负责人把关目标和验证回路。对本项目就是问“这个证据能支持哪一级试戴”，无需逐行代替AI写实现。
- [Mitchell Hashimoto的采用经历](https://mitchellh.com/writing/my-ai-adoption-journey)：清晰小任务、可运行验证会改善代理结果；先交给AI它能自检的工作，反复失败就改检查工具／约束。本文不是要求你亲自重做每次提交或保持代理常驻。
- [Simon Willison的模式集](https://simonwillison.net/guides/agentic-engineering-patterns/)及[线性讲解](https://simonwillison.net/guides/agentic-engineering-patterns/linear-walkthroughs/)：结合真实问题按需讲解，成果仍需审查／测试。我们只讲当前电流路径、一次故障或一个保存边界。

每个可用于面试的案例保留五件事：问题／假设、版本与控制变量、原始数据、结论及不能证明的部分、由证据作出的下一决策。例如“白屏电压回弹为何不等于恢复容量”“固定NTC为何不等于电芯温度保护”“排针分轨为何不等于整机电流”。人类能解释这些因果，比背下整个目录更有价值；不新增固定课程或打卡。

本轮资料边界：网页文字及用户图片为资料证据；没有模型几何检查／切片／打印、固件新编译或硬件实测。模型／视频访问受限、喇叭及表带接口／含运价未闭合，保留为后续实物和资料任务。未取得资料的毫米数、装配方式和保护效果均不补猜。
