本轮不一并采购第二块主板、备用屏、表冠、定制外壳、专用电流仪或随意挑选的电池。已能借用台式电源，按既定顺序先分解功耗。Nano 的电池充电、保护和稳压路径需要后续单独选型。

后续分期保持已确认的功能范围：

1. 第一阶段在同一套板屏上完成真实 UI、亮灭屏、BLE 最小路径和基础电流记录；使用已有 F411/MAX30102 做启停与超时策略实验。
2. 在目标板上接入独立 PPG 与带 FIFO/中断的六轴 IMU，以及基础振动；逐项核对模块电压、供电控制和增量耗电后采购，不能只凭“MAX30102”或“六轴”名称购买任意模块。
3. 根据实际负载和尺寸选择电池、充电保护、稳压及简易佩戴固定件，进入电池运行与试戴。

后置采购不等于删掉功能；三个月原型仍需真实心率负载、IMU 路径、振动、电池运行及真实使用。

## 4. 为什么仍选 Nano

- 当前已找到匹配内存规格的低成本现货板屏组合，足以进入验证阶段；不必为查不到报价继续搁置路线。
- Core 有更好的测量跳线条件，但官方店商品页目前显示 **283.10 元起**，尚未取得 R16N16 的有效选中报价；这不是 Core R16N16 的报价。它也更大，当前不额外购买。
- 本次店铺“全部宝贝”列表没有看到明确名为黄山派的整机套装，不能据此断言厂家不供货，但没有可直接替代 Nano 的已核实清单。
- N4 不是这次选择的内存配置；A128R16 也不因为名称更大就升级，存储类型和 BSP 需要另行核验。
- Nano 板屏的售卖照片确实展示了运行中的手表 UI，但照片不证明 SDK v2.5.1 的手表示例无需适配，也不证明实际帧率、功耗或七天续航。

## 5. 到货验收与证据

到货先清点主板、屏幕本体、转接板、匹配排线，核对丝印版本和卖家资料；通电前确认接线方向、电源电压及原理图。按正确板级目标编译并点亮，测试触摸全区、按键、亮度、熄屏恢复，以及 Flash/PSRAM 容量。先完成基础检查再做不可逆的焊接或结构改动。

第一轮重点不是扩展页面数量，而是测“交互时有多大耗电、熄屏后哪些负载还在运行、BLE 连接与唤醒是否稳定”。预算和资料允许启动实验，续航与佩戴体验仍需要真机验收。
