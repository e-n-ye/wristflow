# Watchface Artwork

`hour_seven.png` is original faceted numeral artwork for this visual demo,
inspired by the composition of the user's reference photo. The photo itself
is not included in the repository. The transparent image is 342 x 282 pixels.

It is a static sample hour, not a complete clock font or a functioning clock.
The official editor converts it to `hour_seven_data.c` as ARGB8888 data.
