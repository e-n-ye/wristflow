# B-R2 主板

本版候选主板采用 0.80 mm 六层结构。初排包含 132 个器件或焊盘组，EPRO 评审版原理图含 11 页。自 11/25 起原理图母版为 KiCad 可读版，含目录共 7 页，见[硬件入口](../../README.md#kicad-原理图)。屏侧为顶层，板框沿用 R2 结构 XY 坐标，天线朝 −Y。
