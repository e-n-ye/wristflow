## U1 有哪些脚可以分配

**源码与模组手册。** SF32LB52-MOD-1-N16R8 的 68 脚中，44 脚有 PA 号（PA00–44 中仅缺 PA21），另有 16 地、3 个供电或电池检测脚、4 个专用音频脚和 1 个 NC。模组焊在 F 面，天线朝 −Y。表中东为 +X，北为 +Y，全部坐标取装配视角。U1 东列 X=2.075，西列 X=−15.075，北列 Y=5.275 mm；49–60 是腹部地阵列，63–68 是模组底面两列信号盘。查盘时不要直接套用手册天线朝上的顶视图。[装配坐标说明](../../boards/b-r2-main/README.md) · [SDK 锁](../../../sdk.lock.json)

| 分组 | 在此型号与电路上的结论 |
|---|---|
| 固定高速、下载和按键 | LCDC1 的 RSTB/TE/CS/CLK/D0–3 依次用 PA00/02/03/04/05–08；五根高速线保留源端 22 Ω。PA18/19 分别为模组 ROM 下载 RX/TX，与 SWDIO/SWCLK 共脚，经 R12/R11 各 100 Ω 到治具。PA34 是高有效 PWRKEY、约 10 s 长按复位。PA44 接 R14/R15 的 VBUS 分压，作为本板检测输入保留。 |
| 模组内部占用与启动 | PA12–17 全接内置 MPI2 16 MB NOR。六枚内排盘在主板网表显示未接，仍须留空。PA13/17 分别为 BOOT_STRAP[1]/[0]，手册启动表中 SPI NOR 为 L/L。PA22/23 已接内部 32.768 kHz 晶体。17 脚是 LDO3 输出，27 脚是受控 VSYS 输入，61 脚是 VBATS 检测；62 按表 3-1 的 NC 处理（图 3-1 标 VCC，不据该图接电）。DS p.3、5–8、23–25、32。 |
| 模拟输入与输出 | PA28–34 各自固定接一个 GPADC 输入，同时可切数字复用。DS 表 3-1 用 CH1–7，图 7-7 用 CH0–6，逐脚列两种编号；SDK 的 PA28 示例也写作 CH1 / API channel 0。电池仍走独立 VBATS 和 `bat1` 通道 7。U1.33/34 差分 DAC、.36 MIC_BIAS、.37 MIC_ADC_IN 均是独立实体脚。DS p.6–8、23、32。 |
| 串行和 PWM | 每个 PA 的 FSEL 4 对应串行路由，FSEL 5 对应定时器路由，再由 PINR 分配实例与通道。每个 PA 在硅片上可选 I2C1–4 的 SCL/SDA、USART1–3 的 RXD/TXD/RTS/CTS，以及 GPTIM1/2 各 CH1–4、ATIM1 CH1–4、CH1N–3N。互补脚跟随同号主通道，同定时器共用周期。另可选 LPTIM1/2 OUT；ETR、BKIN 属输入。每个外设信号只认一项 PINR 选择，重映射会覆盖旧脚。模组内部占用和上述板上固定功能优先。 |
| 唤醒 | `QueryWakeupPin` 对 PA24–44 返回 PA 号减 24。可接实体脚的为 **PA24–27、PA34–44，共 15 脚**。PA28–33 的索引 4–9 在硅片中接地；普通 GPIO IRQ 仍可用。PA24–27 分别共用 PBR0–3，启用 AON 输入会切换 PBR 模式，不能同时用作 PBR 输出。HCPU DEEP 的 HPAON 源与 Hibernate 的两个 PMU 外部引脚槽分别配置。 |

**逐脚出处。** CSV 的 `DS` 采用思澈《DS5203-SF32LB52-MOD-1 V0.2》正文页码，PDF 文件页码为正文页码加 4。模组原理图 6-1/6-2 和表 7-1 优先用于判定晶体、Flash 与启动限制。表 3-1 的 I/O 默认类型没有给出各外接负载在整个复位窗口的电平；表中未指明的时序和电平均待核。DS p.32 建议 IO 接口 3.3 V，晶体、NOR 和 SDIO 的限制适用于本型号。

## 方案一中与选脚相关的五处问题

**CAD 回读。** 铜长为该网所有铜段的平面中心线长度之和，含分支；孔数为该网实际通孔数，含未接通的扇出孔。表内交叉只数中间无地层的 L3/L4 上两段中心线内部相交，排除端点接触及投影重合。屏线包括 CLK/D0–3 的串阻两侧以及 CS/TE/RSTB；音频组为 ADCIN、MIC_BIAS、MIC_GND、DAC1P/N。交叉次数描述占用走廊与后续复验工作，电气耦合幅度待测。

| 优先级 | 对照铜长 / 孔 | 走过的区域、归因及局限 |
|---|---:|---|

## 两档怎么选

**估算方法。** 仅移动同一网络的 U1 端，保留所有其它焊盘中心（包括上拉、钳位、串阻和触点的两个盘）。两点边权用 45°/90° 无障碍最短长度 `max(|dx|,|dy|) + (√2−1) × min(|dx|,|dy|)`。用最小生成树连接所有盘，原树长减新树长作为换脚收益。这个模型允许跨越障碍、忽略层和孔，不含共享分叉点优化。实际铜长和孔数须在重布后回读。相同端点、相同口径也适用于未通的网。

各行按职责读，数值为 **PA 号（U1 脚号）和端点树 mm**。表中列出全部变更项，所有保留项及释放的脚见逐脚 CSV。

|---|---:|---:|---:|
| 触摸复位 → J201.23/D5 | 09 (38) · 32.06 | **32 (16)** · 12.63 / 19.43 | **32 (16)** · 12.63 / 19.43 |
| 功放 CTRL → U6.1/R29 | 42 (4) · 33.01 | **20 (28)** · 9.93 / 23.08 | **11 (31)** · 9.48 / 23.53 |
| 马达门控 → R37.1 | 20 (28) · 24.68 | **42 (4)** · 10.82 / 13.86 | **38 (10)** · 8.08 / 16.60 |
| IMU INT1 ← U13.4 | 31 (25) · 16.84 | **43 (3)** · 11.37 / 5.47 | **36 (12)** · 4.28 / 12.55 |

**布局取舍。** 保守档以功放和马达交换原脚，PA43 接 IMU，保留 PA35/36 的 USB 选项。完整档同时改善表冠、充电和电源分支，将 PA35/36 用作输入；四针治具由 PA18/19 服务。两档都维持三条独立 I²C 总线及原有上拉电源域，保留 PWRKEY、VBUS_DET、PPG_INT_N、显示和模拟链。完整档新用的 PA28/29 只承担数字总线，PA32 只驱动触摸复位，均未分配专用唤醒。

## 每组信号对应的固件变更

## 数据版本与复核

**CAD 回读。** 主检出下的 `artifacts/b-r2-full-routing-20261127/1128-review-copper/WristFlow-B-R2/` 含 KiCad 10.0.8 保存板与配套网表、几何和连通分量。PCB 的 SHA-256 为 `f3981718560871e2652c1c519735a733f2888f0f73bf744e8c480c856ac60916`，与几何文件的 `pcb_sha256` 一致。134 个封装、1,842 段、380 个通孔；本轮用 Python 3.14.3 对 JSON、XML 重新求和与对照，未执行布线或改写板。下面的只读命令可从保存板目录运行。

```bash
sha256sum WristFlow-B-R2.kicad_pcb
python -X utf8 - <<'PY'
import collections, hashlib, json, math
from pathlib import Path
g = json.loads(Path('geometry.json').read_bytes())
assert g['pcb_sha256'] == hashlib.sha256(Path('WristFlow-B-R2.kicad_pcb').read_bytes()).hexdigest()
length = collections.Counter()
holes = collections.Counter(v['net'] for v in g['vias'])
for t in g['tracks']:
    length[t['net']] += math.dist(t['start'], t['end'])
for p in g['footprints']['U1']['pads']:
    print(p['pin'], p['xy'], p['net'], round(length[p['net']], 3), holes[p['net']])
PY
```

**独立校验。** 直接解析原生 PCB 的 footprint、pad、segment、via，以 `X装配=X板−150`、`Y装配=110−Y板` 换算盘心。与 XML 和 CSV 核对 68 脚的网名和坐标、45 行网络的端点、逐层铜长及孔数，结果一致。用整数纳米方向判定重算 L3/L4 交叉，用按边权排序的最小生成树重算两档长度，均与 CSV 的 0.001 mm 精度一致。两档分别有 4/10 个信号换脚，每档无重占；固定和内部占用脚逐一保留。

**需固件或实物验证。** 方案二的完工铜长、节孔数和整板 DRC 需在获准重布后回读；电气行为与维修操作需对应固件和样机实测。
