**原六项分别有局部解。** 西区三版都接通了两条功放输入。北区第二版同时接通 R54 的负载侧和 PPG_INT_N。东区第三版同时接通触摸复位和完整表冠 B。三者在不同保存板上，重新布置的其它网络同时出现断点。把三者的局部连通数相加会落掉这些新断点。

**保底的未结项。** 六网各缺一项，分别为 R54.2→R41.2/U15.3、R27.2→U6.4、R28.2→U6.3、U1.18→J201.23/D5.2、K3→U1.16/R63.2、U1.21→J2.8/R68.2。全板 DRC 另有 K1/K2、K2/K3、K3/K4 庭院重叠和七个单端孔，分别位于 PA_42 (−16.455,3.600)、PA_20_VIB_PWM (3.455,−5.200)、PPG_INT_N (−2.650,6.655)、PA_38 (−1.580,−7.900) 与 (−10.350,6.655)、PA_09_TP_RSTN (3.455,3.600)、OLED_PULL1M (8.875,5.375)。其中 PPG 和 OLED_PULL1M 两个单端孔也见方案一；新增项不能列为既有豁免。六网连通、单端孔、锐角和短段验收均未结清。

**验证记录。** KiCad 10.0.8 重灌并保存，FreeCAD 1.1.4 从该板 STEP 和 169 实体的薄装配回读。各区域再次导出完整 XML，与冻结版逐脚比对。先保存 DRC、铜、局部连通和板哈希，再独立计算参考面、过孔、内层交角、麦克风、BTL、充电、钢网和闭盖；某条线路未通时仍记录其余项目。对落选版另作独立机械检查，记录真实的器件干涉和横向约束违规，逐版表中条数可含同一器件对的多种判据。QSPI 的串阻两侧有开路时，屏线表的长度和缺口只代表残铜，不能签收信号通路。
