## 工程师审查与下一步决定

1. **保留固定件和各项阈值，另开有界试验。** 优先让 TE 先向南绕过表冠侧凹口，按整条铜和普通孔的真实外径扣 0.30 mm 板边；同时在实际接铜层按完整孔环而非钻径避让。以 P2 的干净屏控通路为几何对照，把 OLED 和四个触摸回流位纳入同一出口，再测全网及钳位/去耦距离。本轮三次已经结束。
2. **滤后双线按等距折弯一起移动。** 外侧折点单独偏移造成 0.015162 mm 超差；建议给 0.60 mm 留工艺余量，再复量两条中心线的最大间距、环面积及分支。布局先禁入屏尾回程的横向/垂向公差区，再移动上述八件；不需要改屏槽、旋转 J201 或放宽门限来验证这些假设。
3. **电路建议仅供审查。** 触摸复位和 OLED 复位若共用，可以少一根东侧控制线，但触摸独立掉电、睡眠恢复、两器件复位低脉宽与释放时序都要先拿到同版资料和波形。自动上电复位还须兼顾 ROM 四线烧录、低电压热复位及现有 U19/R58 镊子维修路径。两项均未改电路。PA34 的低电压裕量、PA38 的默认输出、夹具实物、IMU/地磁坐标系继续由硬件与固件共同验收。

## 复现与证据版本

代码使用锁定 SDK，未改 SDK、未构建或烧录固件。四板 EPRO 恢复输入与 KiCad/FreeCAD 的 D 盘位置沿用[硬件复现入口](../../README.md)。从仓库根目录用 KiCad 10.0.8 自带 Python、CLI 和新输出目录运行下列命令；`RESTORED`、`SCH`、`OUT` 分别指本机恢复目录、原理图新目录和单板新目录，`WHICH` 为 main/rear/crown/bridge。

```bash
python -B hardware/generator/kicad_schematic.py --projects "$RESTORED" --out "$SCH" \
  --kicad-symbols "$KICAD_SYMBOLS" --kicad-cli "$KICAD_CLI" --date 2026-11-28
"$KICAD_PY" -B hardware/generator/kicad_pcb.py --projects "$RESTORED" \
  --schematics "$SCH" --out "$OUT" --cli "$KICAD_CLI" --board "$WHICH"
```

主板生成器先写出 PCB，执行 `pcb drc --schematic-parity --all-track-errors --refill-zones --save-board`，再回读 `geometry.json` 和检查完整扇出；当前会在 J201.1 缺少扇出时非零退出。三小板可分别生成及验算。对 P3 从已提交的数据源重新出板，逐段/逐孔、焊盘和 DRC 类别与保存板相同。PCB 随机对象标识会改变文件 SHA。闭盖可用同版 `pcb export step --board-only --user-origin 150x110mm` 输出 `board.step`，再运行 `kicad_fit.py <主板目录> <薄装配目录> --placement-only`，碰撞/净距未通过会保留 `placement-fit.json` 并非零退出。

本工作树的三份原始保存板、DRC 和连通分量分别在 `artifacts/scheme3/{p1,p2,p3}/WristFlow-B-R2/`，源文件重建在 `artifacts/scheme3/replay/`，独立小板在 `artifacts/scheme3/empty/`。P3 PCB SHA-256 为 `9321708e30807cb04dde1478e575b498469db009df48bff394bf8d90ae7641f9`。包含宿主重启前的工作和首版试验。DRC、分量、Gerber、参考面和闭盖均为 CAD 证据，自研板仍无实物结果。
