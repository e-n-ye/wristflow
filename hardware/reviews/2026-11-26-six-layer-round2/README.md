## 复现与验证边界

从硬件入口恢复 EPRO 并逐板独立求网。用 KiCad CLI 10.0.8、随附 Python 生成原理图和 PCB，传入同一官方屏板配准件。在本机使用 `artifacts/b-r2-round2-20261126/schematic/` 和同目录的 `pcb/`。最终主板 SHA-256 为 `2b9bbac7d9a34e6826302842231f12254f9b152bcc23f877992e5617359e92b3`，共 612 段线。检查设计源见 [硬件复现入口](../../README.md#kicad-pcb)。

```bash
python -B hardware/generator/kicad_schematic.py --projects "$eda" --out "$sch" \
  --kicad-symbols "$kicad_symbols" --kicad-cli "$KICAD_CLI"
"$KICAD_PYTHON" -B hardware/generator/kicad_pcb.py --projects "$eda" \
  --schematics "$sch" --out "$out" --cli "$KICAD_CLI" --screen-reference "$official_screen"
main="$out/WristFlow-B-R2"
pcb="$main/WristFlow-B-R2.kicad_pcb"
"$KICAD_CLI" pcb export step --board-only --drill-origin -o "$main/board.step" "$pcb"
"$FREECAD_PYTHON" -B hardware/generator/kicad_fit.py "$main" "$assembly" --cli "$KICAD_CLI"
"$KICAD_CLI" pcb export gerbers --layers F.Paste,F.Mask,F.Cu -o "$out/gerber" "$pcb"
```

生成器重灌并保存主板，逐板运行 `pcb drc --schematic-parity --all-track-errors` 和 `sch erc`。从保存 PCB 导出几何、孔属性与实铺多边形。pcbnew 检查 U3 封装钢网源，并独立比对导出的 Gerber 曝光。Shapely 2.1.2 检查走线连通、线宽、投影夹角、铜距、空洞与开窗。FreeCAD 1.1.4 重开 169 实体闭盖装配，比对板框 STEP，整机名义总厚 16.845，板 Z 为 8.41–9.21。电池投影内共 38 件，J201 为 0.960，其余最高 0.950。最近中框、屏尾回程和螺钉横向净距分别为 0.31999、0.32171、0.33520。

试排时 DRC 找出了器件庭院冲突；扩大到全部 L3/L4 后又定位到 OLED_VBAT 和屏幕 D2 的重叠，修正后重新生成并复跑。负向检查分别缩窄 DOCK、加入无地层干扰线、清除盖帽、让 BTL 换层和断开 C33，每种改动均触发对应检查。设备、固件和生产订单均未操作。样机仍需验证麦克风底噪、BTL 波形、充电温升、U3 焊点、连接器插合和闭盖公差。
