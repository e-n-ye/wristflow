# B 方案减薄摸底（2026-11-24）

用户要求在 B-R2 上尽量减薄，结构都可调整，换选型须有可购货源；3D 修订由用户完成。本研究只读取已存的 R2 装配和[评审器件表](../../../../hardware/reviews/2026-11-22-b-r2/placement-BOM.csv)，未修改模型或 PCB，结果是厚度预算，尚无实物、装配、射频或光学验证。取舍记录见 [BASELINE](../../../../docs/BASELINE.md#b-thinning-20261124)。

**结论**　保留 SF32LB52-MOD-1、LP503030 450 mAh、原屏、MAX30102，主板仍为嘉立创 0.8 mm 六层。下表组合可从 19.20 mm 档降到 **16.85 mm**，不含凸台 15.51 mm；表圈改为与玻璃近齐平时为 16.73 mm。

| 项 | 做法 | 减薄 mm |
|---|---|---:|
| A | 后盖光学叠层减薄，电芯承托改为开窗托板或中框边沿 | 1.00 |
| B′ | 电池投影内高于 J201 叠高的四个件移出，电机托架抬高 | 0.49 |
| C | 模组屏蔽罩到屏背排线 0.51 → 0.30 | 0.21 |
| D | 屏厚按同类规格 2.46 计 | 0.50 |
| E | 凸台 1.50 → 1.34，与电芯底面同时受限 | 0.16 |

Z=0 为平背外表面。R2 一列由 `thinning_budget.py` 从本机 R2 装配读出；19.20 档沿用评审的主板后移 1.40、屏座再降 0.30。

| 电芯成品上限 | 5.30 | 5.30 | 5.30 |
| 电芯绝缘 | 0.10 | 0.10 | 0.10 |
| 绝缘层到主板背面 | 3.55 | 2.15 | 1.66 |
| 主板 | 0.80 | 0.80 | 0.80 |
| 模组 | 3.10 | 3.10 | 3.10 |
| 模组到屏背排线 | 0.81 | 0.51 | 0.30 |
| 屏背排线与屏周胶 | 0.27 | 0.27 | 0.27 |
| 屏组件 | 2.955 | 2.955 | 2.46 |
| 玻璃到表圈 | 0.165 | 0.165 | 0.165 |
| **合计** | **20.90** | **19.20** | **16.85** |

## 各项做法

**A　后盖光学与电芯承托**　原电芯底面被 PPG 叠层顶住：光窗 0.65、窗到芯片 0.30、MAX30102 1.55、柔板 0.12、胶 0.05、补强 0.30，再加 0.41 间隙和托板。改为光窗 0.50、窗到芯片 0.10、补强用嘉立创柔板可选的 0.2 mm 钢片，PPG 叠层顶面由 1.49 降到 1.04。后盖柔板在电芯下方 Z 1.02–1.14 穿过，改走后盖内 0.15 mm 浅槽。托板减到 0.20 mm 并在 PPG 区开窗，或取消整板、由中框边沿与胶承托；按 0.15 装配间隙和 0.10 胶，电芯底面取 1.35。此后 MAX30102 不再限制厚度，换 MAXM86161（1.4 mm）没有收益。充电触点尾部最高 1.02，与托板下表面 1.05 的余量需在 3D 中复核。

**B′　电池投影内的高件**　屏尾位置与黄山派相同，穿板后紧贴板面，J201 不能移出电池投影。J201 插合件、屏尾和补强在板下合计 0.96 mm，保留 0.20 装配量与 0.50 鼓胀余量后，主板背面到电芯绝缘为 1.66 mm。需要处理：

- U4、U15（ETA5055V330DS2F）、U21（XC6219B182MR）按 SOT-23-5 留 1.45 mm，D19（B5819W）留 1.35 mm，合计约 36 mm²。可移到屏侧，落在模组 3.1 mm 高度以内，19.20 档屏侧 ≤1.25 mm 空区约 363 mm²；也可换成 TLV75533PDQNR、TLV75518PDQNR（X2SON 1×1）和 PMEG2010AEB（SOD-523）或 NSR10F20NXT5G。
- 中框一体电机托架下沿低于主板背面 1.68 mm，需抬高 0.72 mm。
- 外贴 NTC 与 J201 在 Y 8.15–8.56 重叠，需在电芯顶面另找位置或移到侧边。
- 0603 件、压紧螺钉板下 0.60 mm 及屏尾回程均不超过 0.96，可保留。

J201 的 0.96 mm 来自模型中的 CN1、插头和补强示意包络。实测每少 0.1 mm，整机同样减薄 0.1 mm。

**C、D、E**　模组屏蔽罩顶贴 0.05 mm PET 后，到屏背排线留 0.30。屏厚原取同类 HARESAN 包络 2.955，W-010 机械图未核；同为 1.85 寸 390×450、CO5300 的 YTL CWS05 含盖板 2.46，有效区 30.72 × 35.48 与模型一致，用户判断可信。CWS05 触摸为 CST820，与原屏 FT6146 不同，只作原屏偏厚时的备选。11/03 实测玻璃面到主板背面 11.32 mm，含屏板和两板间距，不能拆出屏厚；屏与屏板分开时复核。保留托板时，PPG 余 0.16，凸台可同步降到 1.34。

**表带端**　主板背面在 Z 8.41。喇叭顶面 5.48，电池插头和三路测流短接帽在板下分别悬出 1.55、1.88，扣 0.20 间隙后仍余 1.18、0.85。短接帽不必改矮；可拆桥件仍为机械占位，标准 2.54／2.0／1.27 mm 跳线帽高度均超过 1.88 mm。

**表冠**　主板背面比 R2 靠近后盖 2.89 mm。编码器 Z 5.85–9.75、立板 4.63–13.13 和板顶弹片接口需在 3D 中重新定位；BMQ22 和 Ø6.6 冠帽仍在 15.5 mm 机身侧壁以内。

## 未采用与暂缓

| 方向 | 结果 | 原因 |
|---|---|---|
| SF32LB525UC6 裸芯 | 屏侧最高约 1.2 mm | 用户排除：射频、晶振、存储和布板复杂度高 |
| 主板 0.6 mm | −0.20 | 嘉立创 4／6 层最薄 0.8 mm |
| J201 移到屏侧或表带端，电池投影背面全空 | 15.89 | 屏尾位置固定 |
| 同占位 4.0 mm 电芯，约 350 mAh | 15.75 | 需 15×11×3.0 mm 喇叭；用户认为约 1.1 mm 不构成核心体验 |
| LiPol LP353035，3.5 mm 400 mAh | 约 15.2 | 长 35 mm，表带端喇叭和插头需重排 |
| 电池与主板并排 | 11.6–12.1 | 电芯约 200–300 mAh，主板变长条、天线靠电芯；用户不推荐 |
| 模组翻到电池侧 | 与电池重叠时最好持平 | 要不重叠须把电芯缩到约 24 mm 宽并迁走喇叭，约 14.2 mm，属并排的变体 |

## 本机复现

FreeCAD 1.1.4，在仓库根目录用 Git Bash 运行。工作目录需含 [B-crown](../../2026-11-22/B-crown) 第 12 步生成的 R2 装配；11/24 使用的本机模型 SHA256 为 `d1141028720b98cbb97d37a1c032ef2bee0dfc2a601073d711b47019920f70a9`。

```bash
export WRISTFLOW_B_WORKSPACE="$(cygpath -am artifacts/wristflow-b-source-review-20261124)"
python -B mechanical/b-enclosure/run.py --freecad '<本机 FreeCAD.exe>' \
  --script 2026-11-24/B-thinning/thinning_budget.py --out "$WRISTFLOW_B_WORKSPACE/2026-11-24/B-thinning"
```

[`thinning_budget.py`](thinning_budget.py) 只读模型，输出 `budget.json`，其中包含逐层值、试算假设、四个高件、表带端余量和暂缓项总厚。
