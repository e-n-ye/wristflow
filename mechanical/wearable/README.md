# 外壳 A0：FreeCAD 尺寸与布局研究

这是可打开、可改参数的结构评审草案，**禁止直接打印／试戴**。活动项与唯一下一步仍以 [STATUS](../../docs/STATUS.md#current) 为准；本阶段结果见[可佩戴专题](../../docs/WEARABLE-PREPARATION.md#cad-a0-20261107)。

## 源码与本机产物

- `parameters.json`：毫米参数，每项保留数值、来源类别和说明；实际测量、厂家本体公差、V1.2参考和设计假设分开。
- `build_freecad.py`：调用FreeCAD原生Part／Mesh／Spreadsheet建立依赖图；保存后无需安装自定义Python代理即可打开。`run.py`是普通Python启动器。
- `validate.py`／`check_freecad.py`：原生重新打开、重算13对限定碰撞、改变电池厚度／壳宽再恢复、STEP往返及天线带移入电池的碰撞负控；只在内存改动，不保存输入模型。
- `render.py`／`review_freecad.py`：独立FreeCAD进程通过原生GUI API导出视口图，不控制用户已打开的窗口。渲染会保存模型的颜色、透明度与默认开盖视图，完成后再核产物哈希。

社区模型来自用户下载的“黄山派适配模型（watch表带版本）【个人制作】.zip”，SHA256锁在参数源中。取得合法本机副本后显式传入；不下载、替换或公开再分发源网格。含该几何的FCStd、STEP、视口图及临时宏留在忽略的`artifacts/`，不提交到公开仓库。每次生成必须用新输出目录，既有／失败产物保留。

## 复现

已验证FreeCAD 1.1.4（原生Python 3.11）；普通Python启动器仅用标准库。以下路径为占位，填入本机实际值，输出目录必须位于可写的本地位置。不会烧录、操作设备或安装软件。

```bash
python mechanical/wearable/run.py \
  --freecadcmd '<FreeCAD安装目录>/bin/FreeCADCmd.exe' \
  --source-zip '<本机原ZIP绝对路径>' \
  --out artifacts/<新的CAD输出目录>

python mechanical/wearable/validate.py \
  --freecadcmd '<FreeCAD安装目录>/bin/FreeCADCmd.exe' \
  --out '<输出绝对路径>'

python mechanical/wearable/render.py \
  --freecad '<FreeCAD安装目录>/bin/FreeCAD.exe' \
  --out '<输出绝对路径>'
```

依次核`build-result.json`、`native-validation.json`及A／B的`visual-review_*.json`都是`status=ok`，再人工看全部视口图。**FreeCADCmd可能在Python异常时仍返回0**，不能只认进程退出码。`run.py`及`validate.py`核结构化报告，渲染工具核独立结果和图片存在。原生检查A／B都存在才适用，不对单方案目录运行。

生成物：`WristFlow_A0_{A|B}_NOT_FOR_PRINTING.FCStd`、对应STEP、三个原生视口PNG、参数／配准／有限碰撞报告。打开FCStd后在树中编辑`P`表的B列（别名可在表达式中查看）；已验证电池厚度与壳宽联动。板形／孔位／CN3由配置生成时固化，改变RigidFitTX／TY必须改JSON后重建，表格改值不移动这些参照。MotorXOffset及ScrewR只作比较记录，尚非完整联动入口。修改模型后须在新的输出目录重建、渲染和核验；旧JSON不会自动更新，不要把旧报告当修改后模型证据。原生核验会重算保存模型的13对碰撞，并核STEP与当前后舱／后盖体积一致；它不重新生成STEP，修改后的导出须同步。

## 结构、检查与剩余条件

原前框、按钮、横杆只作网格参照，原底盖保留并转换为实体；新后舱接在其外侧，保留隔板／固定结构，低框作侧向定位，可拆后盖用两个暂定孔柱。电池本体34×21×10、喇叭本体30.2×20.2×7.1、电机名义Ø10×2.7分别建实体。A电机放喇叭侧边，B使用独立桥架错层，不让电机压在喇叭或电池上。**未完成电池竖向防脱、线束通道和紧固件选型**，侧框不等于可靠电池固定。

V1.2板形／孔位只作参考，未替代用户V1.1实测。核心板TOP面朝后，在当前视图需X翻面；USB位于原模型正X侧、按键负X侧。孔位仅刚体配准，RMS约0.240mm，禁止缩放板卡消掉误差。原盖柱顶作为主板背面Z是假设；模型玻璃前沿可能高于前框，尚无唯一承力／接触基准。外伸金色柱依用户确认不纳入装配，板间支柱／FPC保留；程序没有实际拆改设备。

有限检查包括：最终实体有效且连通、后舱／后盖与三个本体不穿透、本体互不穿透、本体不进暂定天线带。13对交集体积阈值0.001mm³是数值检查容差，**不是打印／安全净距**。CN3另有丝印主体投影＋全局4.78mm高度的局部诊断，不能当完整跳帽包络。天线带是设计预留，未证RF净距。

完整封装电池及保护端、接续胶带、线弯／接头解锁、BAT／SPK／UART路径、FPC弯曲和屏幕压边、USB插头、表带锁止与转动、所有螺丝头／啮合／尖端均未建立完整实体。原底盖隔板不能视作无障碍电池出线，必须闭合通路后才谈装配；B桥架下方的喇叭装入／取出路径也未验证，需核装配顺序或可拆桥架。喇叭本体当前是保守长方体，声孔／朝向／侧向声道仅提案，声学和磁体干扰待验。壁厚／定位框／间隙／材料、贴肤棱边、刚度／温升未验。无STL制造导出，不作整机可装、打印或腕戴放行。
